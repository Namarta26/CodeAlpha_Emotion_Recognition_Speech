# CodeAlpha_Emotion_Recognition_Speech

# Emotion Recognition from Speech

## Overview

This project focuses on **detecting human emotions from speech audio data** using machine learning techniques. The model analyzes audio features to classify emotions such as happy, sad, angry, or neutral.

## Objective

* Extract features from speech signals
* Train a model to recognize emotions from audio
* Evaluate model performance

## Technologies Used

* Python
* Jupyter Notebook
* NumPy, Pandas
* Librosa (audio feature extraction)
* Matplotlib / Seaborn
* Scikit-learn

## Dataset

* Speech emotion dataset containing audio files
* Features extracted include MFCCs, chroma, and spectral features
* Target: Emotion labels

## How to Run

```bash
pip install -r requirements.txt
jupyter notebook
```

Run all notebook cells sequentially.

## Evaluation Metrics

* Accuracy
* Confusion Matrix
